# 桐House一家・家庭旅行手帳 PWA v6.1

## 📦 完整備份・搬家
這版把「完整備份」設為主要備份方式。

完整備份包含目前 `hotel_memories_v1` 內的整本住宿資料：
- 飯店與地點
- 國內／國外
- 入住與退房日期
- 房價、房型、訂房方式
- 評分、備註、值得再住
- 旅行貼紙
- 手帳中已保存的住宿照片（Base64）
- 其他住宿紀錄欄位

匯出會得到 `桐House一家_完整搬家備份_YYYY-MM-DD.html`。
日後在新手機開啟備份檔，會顯示住宿筆數與照片數，並開啟原本部署的桐House手帳，最後再次確認後才取代目前資料。

## LINE
LINE 快速分享仍保留，但明確標示「不含照片」；需要真正完整搬家請使用「📦 完整備份・搬家」。

## 重要
請維持原 GitHub Pages 網址。完整備份頁會記住匯出當下的手帳網址，還原時會回到該網址。
