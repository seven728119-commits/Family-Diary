## 邏輯統一
- 「住最久」一律用住宿晚數，同晚數並列。
- 「最常回訪」只有同一旅宿實際入住 >= 2 次才成立；所有旅宿都只住 1 次時顯示「還沒有回訪過的旅宿」。
- 國內地區會把「宜蘭礁溪 / 宜蘭羅東」歸到「宜蘭」，「桃園大溪」歸到「桃園」；城市回憶仍保留原始輸入。
- 年度最常停留用實際城市/地點，不再混用「國內城市」與「國外國家」兩種不同層級。
- 旅宿家族「住過」只統計已完成住宿；未來安排另外顯示。
- 待評分只以「尚未評分」為提醒條件，備註維持自由，不會因沒寫備註一直提醒。
- 首頁累積旅宿改算「不同旅宿數」，不是住宿紀錄筆數。
- 入住中會顯示「正在旅行中 / 入住中」，不再出現負數倒數。
- 國內 / 國外沒有已完成住宿時，平均每晚顯示「—」，不顯示誤導性的 $0 / 晚。
- 足跡改成「晚數 + 入住次數」，比單純筆數更有回憶意義。
- 避雷是紀錄，不做競賽排名。
