# 桐House一家・家庭旅行手帳 PWA v6.8

## 年度回顧改成「一家人的旅行年鑑」
這版把平均評分從年度回顧主角拿掉。評分用來找出有意義的回憶，而不是把不同旅宿平均成一個沒有故事的數字。

### 年度回顧現在會看到
- 今年一起住過幾次、幾晚，以及停留最久的地方。
- ♡ 今年最喜歡：評分最高優先；同分時「還想再住」優先。使用照片、回憶一句、貼紙或備註說明原因，不自行編造。
- ☁️ 這次就留在回憶裡：只有真的出現 1–2 星住宿才顯示具體旅宿與已記錄原因；沒有低分住宿時不硬挑最差。
- 今年旅行關鍵字：只從實際使用過的旅行貼紙統計，最多 5 個。
- ✨ 今年第一次：優先找第一次出現的新城市，其次新旅宿集團、第一次回訪等。
- 住宿花費與平均每晚收進「再翻一點今年的回憶」，不搶年度回憶主畫面。
- ✎ 留給今年的我們：每個年份可以自己寫一句話，存在本機 localStorage。
- 年度最後用一段短短的家庭旅行文字收尾。

### 資料相容
沿用原本 `hotel_memories_v1`。既有住宿紀錄、照片與 JSON 完整搬家功能保留。
