# 桐House一家・家庭旅行手帳 PWA v6.6

## 統計邏輯統一
- 最常入住城市：改為依住宿晚數，同晚數並列。
- 去最多國家 / 國內地區：維持住宿晚數，同晚數並列。
- 最常回訪：原「收藏亮點」改名，依同一旅宿入住次數，同次數並列。
- 最愛旅宿：評分優先，再看「值得再住」；相同條件顯示相同名次。
- 避雷：1–2 星集中呈現，不硬做排名。
- 花費排行：依住宿總金額，同金額並列。
- 平均每晚：總住宿金額 ÷ 總住宿晚數。

## 年度旅行回顧
- 不再堆四張以上 KPI 卡片，改成一頁式「年度年鑑」。
- 首頁只顯示：住宿次數、住宿晚數、最常停留、總花費。
- 額外數據收進「看看這一年更多統計」折疊區。
- 同晚數最常停留會並列，例如：沖繩、宜蘭｜各 4 晚。
- 一筆住宿紀錄改稱「一次住宿」，不再誤叫成「一趟旅行」。
