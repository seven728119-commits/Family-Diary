# 桐House一家・家庭旅行手帳 PWA v6.2

## iPhone 完整搬家版
不再依賴 iPhone 從「檔案」App 執行 HTML / JavaScript。

### 📤 搬出手札
會建立一個 `.tonghouse` 真正資料檔，內容包含：
- 全部住宿資料
- 日期、國家、地區
- 金額、訂房資訊
- 評分、備註、貼紙
- 手帳內保存的照片

若 iPhone 支援檔案分享，會直接叫出 iOS 分享選單，可選 AirDrop；若不支援則下載檔案。

### 📥 搬入手札
新手機打開已部署的桐House → 工具 → 搬入手札 → 選 AirDrop 收到的 `.tonghouse`。
手帳會顯示備份日期、住宿筆數、照片數、目前手機筆數，再確認是否合併。

### 合併規則
- 預設採「合併」而非整本覆蓋，較安全。
- 相同住宿 ID：使用搬入檔版本更新。
- 不同 ID：兩邊都保留。
- 不會因搬家清掉新手機已經另外新增的住宿。

### 舊功能
- LINE 快速分享（不含照片）仍保留。
- 舊 JSON 備份匯入仍保留。
- localStorage Key 仍為 `hotel_memories_v1`。
