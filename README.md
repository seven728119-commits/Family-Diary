# 桐House一家・家庭旅行手帳 PWA v5

## 這版新增
- 全站 Zen Maru Gothic（正文 500、標題 700）
- 年度家庭手帳封面
- 每筆住宿可加入照片
- 照片自動壓縮後保存在瀏覽器
- 每筆住宿可寫「一句回憶」
- 親子 / 泳池 / 早餐 / 慶生 / 度假 / 購物旅行貼紙
- 首頁年度回憶拍立得
- 國家 / 城市足跡版圖
- 家庭旅行時間軸
- 原有住宿倒數、集團分類、年季月統計、搜尋、備份全部保留

## 注意
照片會以壓縮後的資料存在瀏覽器 LocalStorage。若累積很多照片，建議定期匯出 JSON 備份。
字體使用 Google Fonts Zen Maru Gothic；離線時會回退至裝置內建中文字體。


## v5.1
- 擴充訂房方式選單
- 新增 Trip.com、Klook、KKday、Expedia、Hotels.com、Traveloka
- 新增樂天旅遊、Jalan、一休.com
- 新增台灣旅行社、FHR / THC、點數兌換、團購優惠等分類


## v5.2
- 入住日與退房日整合為「住宿日期區間」
- 點一次即可開啟月曆
- 先選入住日，再選退房日
- 中間日期會以區間方式標示
- 選完自動填入入住 / 退房資料
- 自動顯示住宿晚數


## v5.3 更新
- 住宿退房日 11:00 後自動切換為已入住／已結束
- 旅行結束後若尚未完成評分或備註，首頁顯示待評分提醒
- 評分改為 1–5 星，收藏頁可依評分與低分避雷篩選、評分排序
- 旅行貼紙新增溫泉、海景、山景、樂園、動物、美食、夜景、機場、市區、自駕、雨天、療癒
- 移除首頁重複新增按鈕，統一使用底部「總覽／新增／收藏」快捷列
- 底部快捷列改為更可愛的按鍵樣式，總覽／收藏跳轉時加入明確定位提示
