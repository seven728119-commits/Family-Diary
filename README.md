# 桐House一家・家庭旅行手帳 PWA v5

## 這版新增
- 全站 Zen Maru Gothic（正文 500、標題 700）
- 年度家庭手帳封面
- 每筆住宿可加入照片
- 照片自動壓縮後保存在瀏覽器
- 每筆住宿可寫「一句回憶」
- 親子 / 泳池 / 早餐 / 慶生 / 度假 / 購物旅行貼紙
- 首頁年度回憶拍立得
- 國家 / 城市足跡版圖
- 家庭旅行時間軸
- 原有住宿倒數、集團分類、年季月統計、搜尋、備份全部保留

## 注意
照片會以壓縮後的資料存在瀏覽器 LocalStorage。若累積很多照片，建議定期匯出 JSON 備份。
字體使用 Google Fonts Zen Maru Gothic；離線時會回退至裝置內建中文字體。
