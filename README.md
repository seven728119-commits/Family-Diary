# 桐House一家・家庭旅行手帳 PWA v5.9

## 一鍵還原備份
- 「匯出備份」升級為「匯出一鍵還原備份」。
- 新備份格式為 `.html`：
  1. 在手帳中匯出。
  2. 日後直接打開這個備份 HTML。
  3. 備份頁立即詢問是否開啟桐House手帳匯入。
  4. 原手帳再顯示備份日期、備份筆數、目前筆數，確認後才覆蓋。
- 備份資料透過 `postMessage` 傳回原部署網址，因此不把照片/資料塞進網址，可保留完整住宿資料與壓縮照片。
- 原本 `.json` 備份仍可透過「舊備份匯入」使用，方便相容先前版本。
- 沿用 `hotel_memories_v1`，同一 GitHub Pages 網址升級不會清除既有紀錄。

## iPhone 使用
建議把匯出的 HTML 備份存到 iCloud Drive /「檔案」App。需要還原時直接點開備份；若 iOS 的檔案預覽未執行網頁互動，可選「在 Safari 中打開」後即可進入一鍵還原流程。
